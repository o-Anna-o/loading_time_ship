# Разработка интернет-приложений (РИП) 2025

## Расчет времени погрузки контейнеровоза в порту

Разработанное приложение позволит клиентам создавать и формировать заявки на расчет времени погрузки контейнеровозов в порту, а операторам порта - завершать или отклонять данные заявки
